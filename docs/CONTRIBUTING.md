# Contributing

Thanks for taking a look. This is a personal site, so contributions are
limited to things like typo fixes, broken-link reports, or accessibility
tweaks. Anything else is probably better as your own fork.

## Reporting an issue

- Be specific. "Something is off on Safari 17.2" is much more useful
  than "site broken".
- Screenshots help, especially for layout problems.
- If you can, include a minimal repro (browser, OS, viewport size).

## Small PRs

If you'd like to send a fix:

1. Fork the repo.
2. Create a branch from `main`.
3. Keep the change focused — one concern per PR.
4. Make sure the HTML still validates and the page renders without JS.

## Style

- 4-space indentation.
- Lowercase HTML attributes.
- Avoid adding new dependencies; this site has none on purpose.

## Code of conduct

Be kind. Disagree with ideas, not people. That's it.
